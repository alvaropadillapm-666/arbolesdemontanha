# Árboles de Montaña

Sistema de estrategia y contenido para la construcción del perfil político de Álvaro Padilla (Lima, Perú).

> *"¡Que vengan árboles nuevos a dar flores nuevas i frutas nuevas! ¡Los viejos a la tumba, los jóvenes a la obra!"*
> Manuel González Prada, Discurso en el Politeama (1888)

## Estructura

- `KICKOFF.md`: cuestionario inicial y plan de arranque
- `estrategia/`
  - `01-identidad-y-relato.md`: concepto, arquetipo, pilares, relato y riesgos
  - `02-hoja-de-ruta-2031.md`: calendario electoral y fases 2026–2031
  - `03-sistema-semanal.md`: rutina de 6 h/semana, plantillas y métricas
- `contenido/`
  - `banco-de-ideas.md`: ideas priorizadas
